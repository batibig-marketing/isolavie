# IsolaVie — site web

Site statique (HTML / CSS / JS) de la société IsolaVie — isolation par l'extérieur & ravalement.

- Pages : accueil (avec sections Entreprise, Équipe, Nos engagements, Certifications), Techniques, Particuliers, Professionnels, Recrutement, Contact, Mentions légales.
- Design aux couleurs du logo (bordeaux #9f1815 + ambre #f7a600).
- Photos d'équipe centrées et agrandissables au clic ; images non téléchargeables (dissuasion).
- Images optimisées en WebP, servies depuis le CDN (https://isolavie.vercel.app/img/...).

Site en ligne : https://isolavie.vercel.app

## Déploiement
Site 100 % statique : déployable tel quel sur Vercel, Netlify, GitHub Pages, ou tout hébergement statique (rien à compiler).
